# KOOLAIDS: A LOLCODE INTERPRETER

## Program Description <br/>
A LOLCODE Interpreter using Python Programming Language. <br>
**Specifications:** https://github.com/justinmeza/lolcode-spec/blob/master/v1.2/lolcode-spec-v1.2.md
<br>

## Features of the Program <br/>
* Lexical Analyzer of LOLCODE
* Syntax Analyzer of LOLCODE
* Semantic Analyzer of LOLCODE

## How to Run <br/>
1. Install Python: https://www.python.org/downloads/windows/
2. Open gui.py
3. Run gui.py using the command: "python gui.py"

## UI Navigation
![image](https://github.com/user-attachments/assets/02a576e1-d130-4a49-bddc-6d944e8ccf3d)
1. **Open File** - Used for opening files to run
2. **Lexeme Table** - Table for the list of tokens of the program
3. **Symbol Table** - Table for variable identifiers and its values
4. **Text Editor** - Where the LOLCODE is located and where you can edit the code
5. **Execute Button** - Button to run the program
6. **Console** - Where the result of the LOLCODE appears
