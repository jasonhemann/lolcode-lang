# HOW TO RUN THE LOLCODE INTERPRETER

1. Go to the directory of the file 'main.py'.
2. In the terminal, enter **'python3 main.py'** - the GUI should appear.
3. Select a file using the button on the upper left or type in your LOLCODE program on the designated space for the text editor.
4. Click on **'EXECUTE'** to run the program.

# DEPENDENCIES AND HOW TO INSTALL THEM

The following python standard library modules were used, which can be accessed through importing them into the file:
1. re 
2. itertools

**No external dependencies** were used in the creation of this project.
