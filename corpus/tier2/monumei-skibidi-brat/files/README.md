# Skibidi Brat: A LOLCODE Interpreter

![Skibidi Brat Logo](assets/logo.png)

Welcome to the LOLCODE Interpreter project! This project provides a graphical user interface (GUI) for interpreting LOLCODE programs. Below, you'll find instructions on how to set up, run, and use the interpreter.


## Table of Contents
- [Usage](#usage)
- [Project Structure](#project-structure)
- [Features](#features)

## Usage

1. **Open the application:**
    - Run `python app.py` to start the GUI.

2. **Load a LOLCODE file:**
    - Click on the "Open File" button to load a `.lol` file into the text editor.

3. **Edit the code:**
    - You can edit the LOLCODE directly in the text editor provided.

4. **Execute the code:**
    - Click on the "Execute" button to run the LOLCODE. The output will be displayed in the console section of the GUI.

### Detailed Steps

1. **Running the Application:**
    - Start the application:
      ```sh
      python app.py
      ```
    - When using linux environemtn:
      ```sh
      python3 app.py
      ```

2. **Using the GUI:**

    ![UI Reference](assets/ui.png)

    - **Open File:**
      - Click on the "Open File" button located at the top left of the GUI.
      - A file dialog will appear. Navigate to the `.lol` file you want to load and select it.
      - The content of the file will be displayed in the text editor section of the GUI.
    - **Edit Code:**
      - You can make changes to the LOLCODE directly in the text editor.
      - The text editor supports syntax highlighting for better readability.
    - **Execute Code:**
      - After editing, click on the "Execute" button to run the LOLCODE.
      - The output will be shown in the console section at the bottom of the GUI.
      - Any errors or messages will also be displayed in the console.

3. **Interpreting Results:**
    - **Console Output:**
      - The console will display the output of the executed LOLCODE.
      - It will also show any error messages if the code has issues.
    - **Symbol Table:**
      - The symbol table section will show the current state of variables and their values after execution.
    - **Lexeme Table:**
      - The lexeme table will display the tokens generated by the lexical analyzer.

## Project Structure

- `app.py`: Contains the main GUI application code.
- `interpreter.py`: Contains the logic for interpreting LOLCODE.
- `syntax_analyzer.py`: Contains the parser for analyzing LOLCODE syntax.
- `lexical_analyzer.py`: Contains the lexical analyzer for tokenizing LOLCODE.
- `semantics_analyzer.py`: Contains the semantic analyzer for LOLCODE.
- `project-testcases/`: Contains various test cases for the interpreter.
- `test/`: Contains additional test files.

## Features

- **GUI Interface:** User-friendly interface for writing and executing LOLCODE.
- **Syntax Highlighting:** Highlights LOLCODE syntax in the text editor.
- **Console Output:** Displays the output of the executed LOLCODE.
- **Symbol Table:** Shows the current state of variables and their values.
- **Lexical Analysis:** Tokenizes the LOLCODE for further processing.
- **Syntax Analysis:** Parses the tokens into an Abstract Syntax Tree (AST).
- **Semantic Analysis:** Ensures the LOLCODE follows semantic rules.
- **Error Handling:** Provides meaningful error messages for lexical, syntax, and semantic errors.
