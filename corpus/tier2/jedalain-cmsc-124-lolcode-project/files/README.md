# CMSC 124 LOLCode Interpreter

This is a Python-based interpreter for the LOLCode programming language. The project is designed to perform the following actions:

- **Lexical Analysis**: Tokenizing source code into meaningful lexemes.
- **Syntax Analysis**: Validating the structure of LOLCode programs.
- **Semantic Analysis**: Ensuring correct usage and context of LOLCode constructs.

---

## Dependencies

This project requires the following:

- Python or higher
- PyQt6 (`pip install PyQt6`)

---

## Installation

Follow these steps to set up and run the project on your device:

1. **Clone the Repository**  
   Clone the project repository from GitHub:

   ```bash
   git clone https://github.com/jedalain/cmsc-124-lolcode-project.git
   ```

2. **Navigate to the Project Directory**

   ```bash
   cd cmsc-124-lolcode-project
   ```

3. **Install Dependencies**  
   On a terminal, use pip to install the required dependency:

   ```bash
   pip install PyQt6
   ```

4. **Run the Program**  
   Navigate to the directory "source_code" and execute the main script:
   ```bash
   cd source_code
   python3 main.py
   ```
